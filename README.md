# MNQ-Trader

전국 대학생 AI 시스템 트레이딩 경진대회(해외선물)용 자동매매. LS증권 해외선물 **모의투자** OPEN API로 CME Micro E-mini Nasdaq-100(MNQ)을 거래한다.

| 항목 | 값 |
|---|---|
| 대회 기간 | 2026-10-19 08:00 ~ 2026-11-13 23:59 (한국 시간) |
| 상품 | CME Micro E-mini Nasdaq-100 (MNQ) 한 가지. 1계약 = 지수 × 2달러 |
| 자금 | LS증권 해외선물 모의투자 계좌 금액 |
| 순위 | 수익률과 MDD를 종합 |

## 준비

1. LS증권 OPEN API 포털에서 **모의투자** 앱키·시크릿을 받는다.
2. 이 폴더에 `keys.json`을 만든다(git에 올라가지 않는다):
   ```json
   {"appkey": "...", "appsecret": "..."}
   ```
3. 가상환경과 패키지:
   ```
   python -m venv .venv
   .venv\Scripts\pip install -r requirements.txt
   ```
4. 연결 점검(읽기만 한다): `.venv\Scripts\python check.py`
5. 서버: 바탕화면의 "MNQ Trader 서버" 바로가기(`start_server.bat`) 또는 `.venv\Scripts\python main.py` → http://127.0.0.1:8775
   - 서버 창에 이름표(MNQ Server) · 컬러 바 · 경과 시간 · 레벨 · 분류를 줄 맞춰 찍는다(`mnq/console.py`, 미리 보기 `python -m mnq.console`). 화면이 몇 초마다 묻는 요청은 찍지 않는다
   - 작업 표시줄 알림 영역에 아이콘이 뜬다. 점이 초록이면 LS 시세를 받는 중, 노랑이면 끊김. 오른쪽 클릭으로 페이지 열기 · 서버 끄기
   - 한 번에 하나만 뜬다. 이미 켜져 있으면 브라우저만 열고 끝난다
   - 창을 닫으면 서버와 가상 계좌의 자동매매가 멈춘다

## 화면

| 페이지 | 내용 |
|---|---|
| 실시간 차트 | MNQ 근월물 분봉(1·5·15·60분, 2초마다 갱신). 고른 후보의 자동매매를 화살표로, 평균 진입가를 점선으로 표시. 오른쪽에 포지션·다음 자동매매·시세·매매 기록 |
| 모의 운용 | 후보마다 $100,000 가상 계좌(정수 계약, 실제 주문 없음). 그래프(모의 운용 / 과거 시험), 대회 기준 4주 구간 성적, 매매 기록, 후보 비교 |

가상 계좌는 평일 뉴욕 16:10에 그날 나스닥100 종가로 노출을 정해 그 순간의 MNQ 가격에 맞추고, 1분마다 LS 시세로 다시 계산한다.
섞기 후보는 장중 갈래도 있어서 평일 뉴욕 10 ~ 15시 정시마다 LS 1시간봉으로 방향(롱·숏·쉼)을 정하고 16시에 정리한다.

## LS 모의계좌 자동 주문 (`mnq/live.py`)

- 모의 운용 후보 하나(`config.LIVE["candidate"]`, 기본 섞기)의 가상 계좌 계약 수를 목표로, 30초마다 실제 포지션과 비교해 차이만 시장가로 낸다
- 대회 시작(`config.LIVE["start"]`, 2026-10-19 08:00 한국) 전에는 주문하지 않는다
- 안전장치: 최대 계약 수, 하루 주문 횟수, CME가 쉬는 시간(뉴욕 17 ~ 18시, 주말) 제외, 주문 뒤 90초는 체결 확인만, 미체결 주문이 있으면 대기
- 켜고 끄기: 작업 표시줄 아이콘 메뉴 "LS 모의계좌 자동 주문". 상태는 실시간 차트 오른쪽 칸. 점검: `python -m mnq.live`(가짜 LS로 판단만 확인)

## 구조

- `mnq/config.py`: API 주소, 키 파일 위치, 상품, 모의 운용 후보
- `mnq/ls.py`: 토큰, TR 호출(초당 한도 지킴), 시세·계좌·주문 함수
- `mnq/strategies.py`: 후보 규칙과 과거 시험(4주 구간 수익률·MDD)
- `mnq/paper.py`: 가상 계좌
- `mnq/chart.py`: 실시간 차트 봉과 시세
- `mnq/server.py`: 웹 서버
- `main.py`: 실행 진입점(중복 실행 막기, 브라우저 열기, 가상 계좌·아이콘 시작)
- `mnq/console.py`: 서버 창 로그 모양 / `mnq/tray.py`: 작업 표시줄 아이콘
- `research/`: 연구 스크립트 (`r1_daily.py`: 일봉 규칙을 4주 구간으로 비교)
- `check.py`: 연결 점검
- `store/`: 토큰, 시세, 가상 계좌 기록 (git 제외)
